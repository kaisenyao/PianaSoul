# The start and end sounds

`cue-active.mp3` (she comes on) and `cue-end.mp3` (she goes off) take ChatGPT's voice start and end sounds as
their reference (`realtime-start-5e7635a2bb70.wav` and `realtime-end-931ae709daff.wav` in the ChatGPT desktop
app), modified for pianasoul.

As they are based on OpenAI's sounds, this repository's MIT license does not cover them.
